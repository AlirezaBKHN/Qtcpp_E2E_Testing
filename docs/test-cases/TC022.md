Title: Dashboard avg-quality-by-technology bar chart matches CSV math

Preconditions:
- Signed in as the seeded e2e user; full seed fixture (unfiltered).

Steps:
1. On Network Data, export the full CSV; per technology, average
   `signal_strength` and map through the shared quality transform
   `(avg dBm + 120) / 0.7`.
2. On Dashboard (default filters), read the tech bar through the pinned
   `techQualityList` items (`<label>: Q.Q%`) and the caption.

Expected Result:
- Group labels equal the CSV's technology set (2G/3G/4G/5G).
- Each readout percent equals the CSV-derived quality within 0.06
  (one-decimal display rounding).
- Caption reads `Avg quality by technology - 4 groups`.
