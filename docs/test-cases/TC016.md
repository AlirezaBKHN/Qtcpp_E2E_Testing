# TC016

Title: Pagination: page windows, page-size selector, label math

Preconditions:
- Signed in (any role); committed DB restored per test (10080 rows,
  `ORDER BY province, id` total order).

Steps:
1. Open the Network Data tab. Default page size is 200: the readout says
   `Page 1 of 51`.
2. Click `Next`; the readout says `Page 2 of 51`.
3. Export the CSV; cross-check the REALIZED id window against the full
   ordered export: the first realized row of page 2 is export row 200,
   and the whole realized window slices the export in order. (UIA
   realizes only the visible rows of a page — the pinned WAD quirk — so
   page-size correctness is pinned by the readout math, not by counting
   DataItems.)
4. Click `Prev`; the readout returns to `Page 1 of 51`.
5. Select page size `50`: `Page 1 of 202`; realized window = export head.
6. Select page size `200`: `Page 1 of 51`.
7. Select page size `1000` (LAST — regrows the UIA tree): `Page 1 of 11`;
   realized window = export head.

Expected Result:
- Every readout matches `Page k of n` math for the selected size over the
  full query; realized row windows align with the CSV export order.
