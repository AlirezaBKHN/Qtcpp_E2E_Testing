# TC020

Title: Dashboard filters narrow the KPIs (province + Search)

Preconditions:
- Signed in as the seeded e2e user; full seed fixture (10080 cells).

Steps:
1. Route via `homeCardDashboard`; read the baseline `kpiCells`.
2. Select province `Fars` in `dashboardProvinceCombo`, click
   `dashboardSearchButton`.
3. Read `kpiCells` and the trend caption.
4. Route to Network Data, apply the same province filter, export CSV.
5. Route back to Dashboard and re-read `kpiCells`.

Expected Result:
- Baseline `10080 cells`; after Search the KPI narrows to Fars.
- The narrowed KPI equals the CSV export's data-row count under the same
  filter (one filter semantics across tabs).
- Trend points between 1 and 7 (caption `Daily quality trend - N points`).
- Filter state survives the tab round-trip.
