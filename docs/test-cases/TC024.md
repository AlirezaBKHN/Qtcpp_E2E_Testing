# TC024

Title: Reports drill-down under filters + filtered export

Preconditions:
- Signed in as the seeded e2e user; full seed fixture.

Steps:
1. On Reports, apply province `Tehran`, click Search, set Group by
   `Operator`, select the first summary row.
2. Check the drill trend chart is displayed.
3. Click `exportReportButton` and read the new `report_*.csv`.

Expected Result:
- The summary narrows to Tehran; the first label (ascending) is
  `Irancell`; the drill chart stays displayed.
- The export carries exactly the current (filtered) summary rows; the
  first exported label is `Irancell`.
