# TC011

Title: Register (fresh name / duplicate / empty password)

Preconditions:
- Automation stack up; committed DB restored per test; the app is on the
  sign-in dialog.

Steps:
1. Toggle to register mode; register `tc011_fresh` / `tc011pass`.
2. Register `tc011_fresh` again with another password.
3. Toggle back through the login screen; register with an empty password.

Expected Result:
- Step 1: `Registered — log in.` (the dialog returns to the login screen).
- Step 2: `Username already exists.` (dialog stays in register mode).
- Step 3: `Password can not be empty.`
