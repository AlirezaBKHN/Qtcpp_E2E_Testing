# TC023

Title: Reports filters + group share pie match the CSV

Preconditions:
- Signed in as the seeded e2e user; full seed fixture.

Steps:
1. On Network Data, filter operator `Irancell`, export CSV; group the
   data rows by technology column.
2. On Reports, apply operator `Irancell` in `reportsFilterSection`,
   click Search, then set Group by `Technology` (popup type-ahead).
3. Read the group pie through `groupShareList` (pinned format
   `<label>: <count> rows (P.P%)`) and the caption.

Expected Result:
- Every slice (label, count) equals the CSV per-technology counts under
  the same filter (4 technologies).
- Summary narrows to the same label set.
- Caption reads `Rows by Technology - 4 slices`.
