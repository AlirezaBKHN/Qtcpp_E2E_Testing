# TC021

Title: Dashboard operator pie matches the CSV-derived share

Preconditions:
- Signed in as the seeded e2e user; full seed fixture.

Steps:
1. On Network Data, filter province `Tehran`, export CSV; group the data
   rows by operator column.
2. On Dashboard, apply province `Tehran`, click Search.
3. Read the operator pie through the readable surfaces: the caption and
   the `operatorShareList` items (pinned format
   `<label>: <count> cells (P.P%)`).

Expected Result:
- Every slice (label, count) equals the CSV operator distribution under
  the same filter (4 operators).
- Caption reads `Cells by operator - 4 slices`.
