# TC017

Title: Row-id DSL: should_contain_row / should_not_contain_row

Preconditions:
- Signed in (any role); committed DB restored per test (10080 rows,
  `ORDER BY province, id` total order).

Steps:
1. Open the Network Data tab; export the CSV for the full ordered id list.
2. On page 1: `should_contain_row(export_ids[0])` passes.
3. Click `Next`; on page 2: `should_not_contain_row(export_ids[0])` and
   `should_contain_row(export_ids[200])` pass.
4. Click `Prev`; `should_contain_row(99999)` must raise AssertionError
   (no such realized id).

Expected Result:
- The row-id assertions reflect the REALIZED ID column of the current
  page only; an unknown id fails with the realized-ids sample in the
  message.
