# TC018

Title: Empty fixture: sign-in works on a database with zero cells

Preconditions:
- Mapped fixture `empty` (`database/fixtures.json`): schema + seeded users
  (admin/guest/e2e_user), ZERO cells — restored and migrated before the
  test by `isolate_db`.

Steps:
1. Launch and sign in as the seeded E2E user (proves users survived the
   cell wipe).
2. Open the Network Data tab.

Expected Result:
- The pager readout says `Page 1 of 1` (0 rows over any page size).
- The status bar says `Showing 0 rows`.
- The table realizes no rows (`realized_row_count() == 0`).
