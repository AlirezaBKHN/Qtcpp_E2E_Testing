# TC012

Title: Login (failure copies + success)

Preconditions:
- The app is on the sign-in dialog; seeded accounts exist (admin/admin,
  guest/guest, e2e_user/e2e123).

Steps:
1. Log in as `e2e_user` with a wrong password.
2. Log in as `no_such_user` with any password.
3. Log in as `e2e_user` / `e2e123`.

Expected Result:
- Step 1: `Wrong password.`
- Step 2: `Unknown username.`
- Step 3: the main window opens; the top-bar readout reads
  `user: e2e_user`.
